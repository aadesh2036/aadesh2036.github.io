    Between Sessions: serverless care-continuity platform for OCD therapy

    WeMakeDevs First Commit Hackathon · React, Node.js, AWS Lambda, API Gateway, DynamoDB, AWS SAM, AWS Cedar

    • Built a full-stack platform where OCD patients log distress and exposure practice between therapy sessions and clinicians get objective longitudinal visibility, designed around trust: privacy-first, safety-first, no gamification.
    • Architected a serverless backend on AWS SAM: 13 decoupled Lambda functions behind API Gateway with a single-table, pay-per-request DynamoDB design; runs locally with cloud parity via SAM CLI.

    • Built a RAG pipeline (Qwen2.5-7B via Hugging Face) that turns patient logs into clinician summaries grounded in ERP literature, with a deterministic fallback when the model is unreachable.
    • Wrote end-to-end suites for auth, security, AI/RAG and user journeys (83/83 checks passing) and built the responsive React + Tailwind frontend.
